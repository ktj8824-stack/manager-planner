# 엄격한 보고 및 작업 지침 (Strict Briefing Protocol)

이 프로젝트를 작업할 때 AI(Antigravity)는 반드시 아래의 규칙을 최우선으로 준수해야 합니다.

1. **선 보고 후 조치 (Briefing First)**
   - 사용자가 질문을 하거나 새로운 작업 지시를 내리면, **절대 즉시 코드를 수정하거나 작업을 실행해서는 안 됩니다.**
   - 먼저 상황을 파악하고, 문제의 원인 또는 **어떻게 작업을 진행할 것인지에 대한 계획(브리핑)**을 사용자에게 명확하게 보고해야 합니다.

2. **사용자 승인 대기 (Wait for Approval)**
   - 브리핑을 마친 후에는 반드시 사용자의 명시적인 승인(예: "좋아 해봐", "작업해" 등)을 기다려야 합니다.
   - 사용자의 명확한 승인 지시가 떨어지기 전까지는 어떠한 파일 수정, 삭제, 생성 작업도 진행하지 않습니다.

3. **대화형 진행 (Conversational Workflow)**
   - 작업은 항상 '사용자 지시 -> AI 브리핑 및 계획 보고 -> 사용자 승인 -> AI 작업 실행 및 결과 보고'의 대화 형식으로 이루어집니다.

4. **지시 사항만 최소 범위 수정 (Strict Minimal Scope - 절대 임의 확장 금지)**
   - 사용자가 지정한 특정 화면, 기능, 파일 이외의 다른 파일이나 코드는 **절대로 임의로 수정하거나 확장하지 않습니다.**
   - 한 번에 여러 파일을 손대지 않으며, 오직 사용자가 지시한 단 하나의 작업 대상만 정밀하게 수정합니다.

5. **브리핑 시 수정 대상 파일 및 범위 명확히 제시**
   - 브리핑할 때 **'어떤 파일의 어느 부분만 수정할 것인지'**를 구체적인 파일 경로와 함께 사용자에게 명확히 제시하고 승인을 받습니다.
